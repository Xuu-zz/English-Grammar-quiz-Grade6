# 译林六上 · 闯关刷题台（施工包）

把这个仓库交给 AI（GitHub Copilot / ChatGPT / Claude），让它按 `SPEC.md` 生成一个单文件 HTML 的英语闯关刷题台。

## 这个仓库里有什么

| 文件 | 作用 |
|---|---|
| `SPEC.md` | **需求说明书**，AI 的施工图：页面结构、6 关梯度、5 种题型、解析规范、18 类变式、验收清单 |
| `PROMPT.txt` | **直接复制粘贴给 AI 的话**（把 SPEC 一起附上） |
| `data/questions.example.json` | 题库格式样例，含真实题目（U2 六关 + U3 三题），覆盖选择/填空/句型/阅读/首字母五种题型 |

## 怎么用（三步）

**第 1 步：建仓库**
GitHub 新建仓库（Public）→ Add file → Upload files → 把本文件夹里三个文件拖进去 → Commit。

**第 2 步：让 AI 写代码**
- 方式 A：在仓库里新建 `index.html`，点右上角 Copilot 图标，把 `PROMPT.txt` 全文粘进去，再把 `SPEC.md` 的内容跟在后面。
- 方式 B：打开 chatgpt.com / claude.ai，上传 `SPEC.md` 和 `questions.example.json`，粘贴 `PROMPT.txt`。

**第 3 步：验收**
AI 交付后，按 `SPEC.md` 第 11 节的 14 条清单逐条点一遍。没过就把它没过的条目贴回去让它改——**一次只改一条**，比让它"再优化一下"有效得多。

## 建议的推进顺序

1. 先只要 **U2 Honesty 一个单元的 6 关**，跑通全流程（这一步能暴露 80% 的问题）。
2. 确认选择题有选项、解析四层齐全、错题本能用。
3. 再让它批量补 U1、U3–U8。
4. 最后才加"限时""排行榜""发音"这些锦上添花的功能。

## 关于教材范围

- 覆盖：译林版（三起）六年级上册 8 个单元（2024 版，2026 秋启用）。
- 六下：2024 版尚未出版，**不要编造课文**。首页留"六下（待更新）"占位，可先用旧版语法做专题卷并明确标注。

## 关于"变式题"

变式不是随机改词，而是 18 个带语法约束的模板：换主语、换时间、换动词、换疑问词，但保证句子成立、答案唯一、错项是真实易错项。见 `SPEC.md` 第 7 节，`questions.example.json` 里的 `variants` 字段列出了全部 18 个考点代号。
